# Working notes

In-flight, **non-authoritative** working docs: planning trails, investigation
logs, design scratch.

1. **Date-first naming.** `YYYY-MM-DD[-slug].md`.
2. **Non-authoritative.** If a note disagrees with `docs/decisions/`,
   `docs/architecture/`, or the code, the authoritative source wins.
3. **Graduation is a move, not a copy.** Promote into architecture/ADRs and
   delete the note.
4. **Deletion is success.** Empty `docs/notes/` is healthy.
